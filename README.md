# 修仙模拟器

一个运行在浏览器中的单人修仙模拟器，提供两条完全独立的道途：持续流转的 **实时修仙 V2.1**，以及一局约 5–15 分钟的 **修仙人生重启**。

- **实时修仙 V2.1**：从底层修士起步，安排日程、追逐因果、踏入秘境，并在现实时间持续流逝中阅读仙途纪要。
- **修仙人生重启**：从 9 个分层随机天赋中选择 3 个，分配 15 点悟性、道心、根骨与气运；按年龄快速经历一生，只在关键命数前做选择，收集结局与人生统计。

两个模式的角色、运行态和存档完全隔离：实时修仙使用 `DAO1.` / `DAO2.`，人生重启使用 `RESTART1.`，互不覆盖。

## 实时修仙 V2.1 玩法概览

### 时间与日程

- 时间以**游戏日**自动流逝，默认现实约 1 秒等于游戏 1 天。
- 支持暂停、1/2/4 倍速；不提供 8× 与 16×。
- 可排定 3/7/14/30 日的行动：闭关吐纳、坊市营生、采集狩猎、游历寻机、洞府养伤。
- 重伤或濒死时，危险日程会自动转为养伤，避免无意义地送死。

### 成长与生存

- 修为、战力、灵根、五维道基、道韵、功法和洞府共同构成角色强度。
- 灵石维持资源循环；疗伤丹可缓解伤势。
- 伤势分为无恙、轻伤、重伤、濒死，会影响日程效率、事件结果和生死风险。
- 洞府会提高修炼和恢复效果。

### 未竟因果与倒计时世界

- 游历寻机和采集狩猎可能发现有期限的遗址或异象，显示在默认的 **仙途纪要** 中。
- 每名修士可同时追逐的因果会随境界从 2 条动态提高至最多 5 条，必须决定自己追逐什么、放弃什么。
- 未竟因果通常会在 3 日后消散，天命因果会在 5 日后落定；时间继续推进时，错过的机缘会由其他修士、势力或传闻接续，并写入纪要。
- 你可主动“放任发展”，保留世界后果而不占用当下决策。

### 四节点秘境探索

- 进入因果会展开入口、药园、岔道、核心共四个节点；每一节点可谨慎探查或强闯夺宝。
- **普通遗址**允许随时撤离，但只带走当前 70% 的战利品。
- **天命秘境**在踏入后会封闭，必须抵达终点或承受其中的风险。
- 节点的成功、收益与受伤概率基于当前战力、悟性、道心、气运、道韵、伤势和选择，而非固定结果。

### 随机事件与日志

- 日志事件自动记录，不打断时间；仙途纪要是主要观察界面。
- 机会事件可在自动策略中选择“暂停决策”或“谨慎自动处理”。
- 即时风险和命运事件会暂停，供玩家选择强行争夺、侦察试探、交涉或离开；处理完毕后会自动恢复时间流转。
- 未竟因果不是即时暂停事件：它会倒计时，世界结果会在玩家未行动时继续发生。

### 生死与道果

- 每 7 个游戏日及踏入重大秘境前会生成道果检查点。
- 普通死亡可回溯到最近检查点，但会损失部分灵石并留下伤势。
- 寿元耗尽或天命秘境中的重大死亡会进入轮回，继承部分道基、功法、道韵与资产。

### 存档

- 游戏会自动保存到浏览器的 `localStorage`。
- 右上角 **道果** 支持导出和导入 `DAO2.` 存档码，可跨浏览器恢复日程、伤势、未竟因果、秘境布局和道果检查点。
- 旧 `DAO2.` 存档会在加载时自动补齐 V2.1 字段；`DAO1.` 存档也可导入并迁移至 V2 会话。

## 修仙人生重启

从模式入口选择 **修仙人生重启** 后，可体验独立于 V2.1 的快速人生局：

- 开局固定展示 9 个命格候选（6 普通、2 稀有、1 传说），选择其中 3 个；部分高品质命格存在轻度代价或互斥。
- 将 15 点基础道基分配到悟性、道心、根骨、气运。天赋会在确认时修正最终属性，并影响灵根、寿元、健康、修为与事件倾向。
- 点击“流转岁月”会自动结算普通经历；少年启灵、入宗去留、秘境、破境、心魔与终局等 8 个关键节点才会暂停决策。
- 一生结束后会显示年龄、最高境界、财富、关键选择与结局；结局图鉴会跨局保留。
- 当前人生局与图鉴使用浏览器独立存档，也可通过 **RESTART1.** 人生档案导出/导入，不会覆盖 `DAO1.` 或 `DAO2.` 道果。

## 开始试玩

前置条件：Node.js 22 或更新版本、npm。

```zsh
cd /Users/yanan.wang/Workspace/VSCodeWork/game1/xiuxian-game
npm install
npm run dev
```

终端会显示本地访问地址，通常为 `http://localhost:5173/`。

试玩建议：创建角色后安排游历或采集，调至 2× 或 4×，留意仙途纪要中的未竟因果。普通遗址可以先试探、战利品足够时撤离；天命秘境则应在伤势、战力与疗伤丹状态良好时再进入。

## 开发检查

```zsh
npm run lint
npm run build
```
