# 修仙模拟器 V2

一个运行在浏览器中的单人修仙生存模拟器。你将从底层修士起步，在天玄大陆安排每日修行、面对机缘与危机，并在时间持续流逝中决定自己的仙途。

V2 在 V1 的角色、境界、战力、天命和 NPC 基础上，改为“实时推进 + 日程队列 + 属性事件 + 生存经营”的核心循环。

## 玩法概览

### 时间与日程

- 时间以**游戏日**自动流逝，默认现实约 1 秒等于游戏 1 天。
- 支持暂停、1/2/4 倍速。
- 可排定 3/7/14/30 日的行动：闭关吐纳、坊市营生、采集狩猎、游历寻机、洞府养伤。
- 重伤或濒死时，危险日程会自动转为养伤，避免无意义地送死。

### 成长与生存

- 修为、战力、灵根、五维道基、道韵、功法和洞府共同构成角色强度。
- 灵石用于维持资源循环；疗伤丹可缓解伤势。
- 伤势分为无恙、轻伤、重伤、濒死，会影响日程效率、事件结果和生死风险。
- 洞府会提高修炼和恢复效果。

### 随机因果

- 日志事件自动记录，不打断时间。
- 机会事件可在自动策略中选择“暂停决策”或“谨慎自动处理”。
- 风险与命运事件必定暂停，玩家可强行争夺、侦察试探、交涉结伴或谨慎撤离。
- 事件结果由修为、战力、悟性、道心、气运、道韵、伤势、丹药与环境共同决定。

### 生死与道果

- 每 7 个游戏日及重大事件前会生成道果检查点。
- 普通死亡可回溯到最近检查点，但会损失部分灵石并留下伤势。
- 寿元耗尽或重大命运事件中的死亡将进入轮回，继承部分道基、功法、道韵与资产。

### 存档

- 游戏会自动保存到浏览器的 `localStorage`。
- 右上角 **道果** 支持导出和导入 `DAO2.` 存档码，可在其他浏览器恢复进度。
- 旧版 `DAO1.` 存档可导入，并自动迁移至 V2 会话。

## 开始试玩

前置条件：Node.js 22 或更新版本、npm。

```zsh
cd /Users/yanan.wang/Workspace/VSCodeWork/game1/xiuxian-game
npm install
npm run dev
```

终端会显示本地访问地址，通常为：

```text
http://localhost:5173/
```

试玩建议：创建角色后先安排 7 日闭关或营生；将速度调至 2× 或 4×，等待机会、风险或命运事件出现。遇到风险事件时，先观察自身战力、伤势、疗伤丹和可能收益，再决定是否冒险。

## 开发检查

```zsh
npm run lint
npm run build
```

生产构建产物位于 `dist/`。如需预览生产版本：

```zsh
npm run preview
```
